About Medical Image Processing

Gaussian Smoothing

Applies Gaussian kernel to reduce noise while preserving anatomical structures in 3D/4D medical volumes.

Wavelet Transform

Performs 3D wavelet decomposition for multi-scale analysis of brain structures and lesion detection.

Segment Tissue

Classifies voxels into tissue types (GM/WM/CSF) using adaptive thresholding for quantitative analysis.

Segment Brain

Extracts brain parenchyma from skull and scalp using hybrid edge detection and morphological operations.

Denoise NLMEANS

Non-local means algorithm for Rician noise suppression in MRI while preserving fine structural details.

Denoise ASCM

Adaptive Soft Coefficient Matching combines multiple denoising results for optimal SNR improvement.

Enhance Image

Improves contrast through histogram equalization optimized for medical imaging dynamic ranges.

Sharpen Image

Laplacian-based edge enhancement to compensate for partial volume effects in high-resolution MRI.

Erode Mask

Refines segmentation boundaries by removing peripheral voxels using 3D morphological erosion.

Dilate Mask

Expands regions of interest to ensure complete coverage of target anatomies in 3D space.

DTI Reconstruction

Computes diffusion tensor metrics (FA, MD) from DWI data using DIPY's TensorModel.
